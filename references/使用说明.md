# 详细使用说明

本文档补充 README 之外的细节：环境搭建排错、歌词对齐原理、可视化风格调优、常见问题。

## 一、环境搭建

### 1. ffmpeg

MV 合成依赖 ffmpeg 及其 libass（字幕）、内置滤镜 showwaves/showspectrum/showfreqs/zoompan。

- macOS：`brew install ffmpeg`
- Ubuntu/Debian：`sudo apt install ffmpeg`
- Windows：下载官方构建或 `winget install ffmpeg`

验证：`ffmpeg -version`，确认输出包含 `--enable-libass`。

### 2. ACE-Step

```bash
curl -LsSf https://astral.sh/uv/install.sh | sh   # 安装 uv
git clone https://github.com/ace-step/ACE-Step-1.5.git
cd ACE-Step-1.5
uv sync                                            # 安装依赖（首次较慢）
```

启动服务：

```bash
uv run acestep-api        # REST API，http://127.0.0.1:8001
# 或图形界面
uv run acestep            # Gradio，http://localhost:7860
```

> 首次生成会自动从 Hugging Face / ModelScope 下载模型（约 4GB），耐心等待。
> 国内网络建议设置镜像：`export HF_ENDPOINT=https://hf-mirror.com`

### 3. Pillow（可选）

仅 `generate_cover.py` 需要：`pip install pillow`。

## 二、歌词时间戳与对齐

MV 的歌词字幕时间戳来源有三种，精度从高到低：

1. **增强 LRC（词级时间戳）**：`[00:12.50]<00:12.50>我<00:12.80>爱<00:13.20>你`
   → 逐字卡拉OK高亮最精准。
2. **标准 LRC（行级时间戳）**：`[00:12.50]我爱你`
   → 逐行高亮，行内按持续时间平滑填充。
3. **纯文本歌词（无时间戳）**：`我爱你\n...`
   → 脚本按歌曲时长**均分**时间戳，可能存在轻微偏移，适合快速预览。

ACE-Step 生成歌曲时，脚本会尝试保存 `.lrc`。若服务端返回的歌词不含时间戳，则自动降级为均分。

## 三、可视化风格调优

`make_mv.py` 的可视化参数：

| 参数 | 默认 | 说明 |
|------|------|------|
| `--style` | wave | wave / spectrum / bars / dots |
| `--color` | 0xFFFFFF | 波形/频谱柱颜色（0xRRGGBB） |
| `--alpha` | 0.9 | 不透明度 |
| `--vis-height` | 160 | 可视化区域高度 px |
| `--position` | bottom | bottom / top / center |

示例：粉色频谱柱、居中、更透明

```bash
python3 scripts/make_mv.py song.mp3 cover.jpg -l lyrics.lrc \
  --style bars --color 0xFF6B6B --alpha 0.7 --position center --vis-height 200
```

## 四、音质与速度取舍

| 目标 | 模型 | 参数 |
|------|------|------|
| 最快预览 | acestep-v15-turbo | `--steps 8`（默认） |
| 更高质量 | acestep-v15-base | `--model acestep-v15-base --steps 64` |
| 平衡 | acestep-v15-sft | `--model acestep-v15-sft` |

MV 编码：

- 默认 `--preset medium --crf 18`（x264），画质优先。
- macOS 加速：`--hwaccel videotoolbox`。
- 快速预览：`--preset ultrafast --crf 28`。

## 五、常见问题

**Q：`无法连接 ACE-Step API`？**
A：先启动服务 `cd ACE-Step-1.5 && uv run acestep-api`，并确认端口 8001 未被占用。

**Q：生成歌曲很慢？**
A：CPU 推理较慢，Apple 芯片（MPS）/ NVIDIA GPU 明显更快；首次还需下载模型。

**Q：中文字幕变方块？**
A：确认系统已装中文字体（macOS 自带 PingFang/STHeiti）。可用 `--font` 手动指定字体名。

**Q：歌词与歌声对不上？**
A：优先用带时间戳的 `.lrc`；纯文本歌词是均分估算，可用带词级时间戳的增强 LRC 改善。

**Q：只想做纯音乐 MV（无歌词）？**
A：生成歌曲时歌词传 `[Instrumental]`，合成 MV 时不加 `-l` 参数即可。
